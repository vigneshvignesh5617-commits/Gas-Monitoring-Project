# Gas-Monitoring-Project

An IoT-based LPG gas leakage detection and monitoring system using MQ-2 sensors and Arduino, designed for home safety and cost-efficiency.

Features
- Real-time gas detection using MQ-2 sensors
- Alerts/notifications (configure per project)
- Backend API and frontend UI scaffolded

Quick start
1. Install backend dependencies:

```bash
cd backend
npm install
```

2. Start backend (example):

```bash
cd backend
npm run start
```

3. Install and start frontend:

```bash
cd frontend
npm install
npm run dev
```

Notes
- Add your environment variables to a `.env` file in `backend/`.
- `node_modules/` is excluded via `.gitignore`.
